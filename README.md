# Certificreate

Certificreate is a certificate generator for quickly producing polished course
completion certificates from a small set of inputs.

## Commands

- `npm run dev` - start the Next.js dev server at `http://localhost:3000`
- `npm run build` - build the production app
- `npm run start` - run the production server
- `npm run lint` - run ESLint

## Planning

Project planning and AI workflow state are maintained locally and are not part
of this repository.
